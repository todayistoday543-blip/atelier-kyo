# 進捗報告コマンド

**kyo-strategist** に作業を委譲してください。

## 実施内容
1. `docs/research/` 配下のリサーチ件数と進捗を集計
2. `clients/` 配下の構築済み・進行中のデモサイト数を確認
3. TodoWrite の現状タスクを参照
4. 未完了タスクの優先順位を再評価

## 報告フォーマット（必ず日本語・フォーマル敬語）

```
## 📊 Atelier Kyo プロジェクト進捗報告
### 報告日: YYYY-MM-DD

### 📈 全体サマリー
- リサーチ完了: X件
- デモ構築中: X件
- デモ完成: X件
- クライアント営業中: X件

### ✅ 直近完了したこと
- ...

### 🔄 現在進行中
- ...

### 🔜 次の1週間で予定している作業
- ...

### ⚠️ ご確認・ご判断いただきたい事項
- ...

### 💡 提案事項
- ...
```

過度な技術用語は避け、Kyoiskyoさんが意思決定しやすい粒度で要約してください。
