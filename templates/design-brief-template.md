## 2. ブランドトーン（kyo-stylist 提案）

### 2-A. 採用ムード（6 ムードからの選定）
**Mood:** {{Tokyo Streetwear}}

選定理由: {{店主のセレクトが黒・白・ネオンの強さに収斂しており、ストリート文脈の客層と一致するため。}}

### 2-B. BrandTokens（暫定値、デザイナー側で微調整可）
```ts
{
  colors: {
    ink: '#000000',
    charcoal: '#0a0a0a',
    bone: '#f4f1ea',
    haze: '#a8a8a8',
    accent: '#bdfd47',  // 酸性グリーン
    accentSoft: '#a8e63f',
  },
  typography: {
    sans: 'Geist',
    mono: 'Geist Mono',
    display: 'Instrument Serif',
  },
  motion: {
    intensity: 'moderate',
    style: 'editorial',
  },
}
```

### 2-C. 「やってほしいこと」「やってほしくないこと」

**Do:**
- 余白を**潤沢に**取る（情報密度 < 美意識）
- 古着が一番似合う背景になっているか自問
- 店主の人格が滲む見出し・コピー
- タイポグラフィ起点でレイアウトを組む

**Don't:**
- ブランドカラーを 4 色以上にする
- Drop shadow の濫用
- Gradient text の濫用
- ロゴを巨大にする（控えめが大人）
- ストックフォトでお茶を濁す（撮影予算が無いなら、グラフィック / タイポで代替する）

## 3. 必要な納品物

### 3-A. 必須
- [ ] **Hero ビジュアル** 1 種（1920x1080 SVG / PNG / 動画 5秒以内）
- [ ] **コレクションサムネイル** 3 種（4:5 比率）

- [ ] **アバウトページ用の素材**（手書き原稿スキャン、過去の写真等）

- [ ] **3D アセット**（GLB / GLTF）— 採用時のみ

## 6. 制約

### 6-A. パフォーマンス予算（厳守）
| 項目 | 上限 |
|---|---|
| 初期ロード JS（Three.js 除く） | 200KB gzipped |
| Hero 画像合計 | 300KB（WebP/AVIF） |
| LCP（mobile / 4G slow） | 1.8 秒 |
| 3D シーン（採用時） | draw calls < 100 / vertices < 30万 |

### 6-B. アクセシビリティ
- WCAG 2.2 AA 準拠（コントラスト比、フォーカス、a11y）
- `prefers-reduced-motion` 完全対応

### 6-C. 法的
- 商品写真は店主が著作権を有する素材のみ
- ストックフォトを使う場合はライセンスを明記
- 著名な商標（Levi's, Champion 等）は商品写真の中で**自然な使用**範囲
