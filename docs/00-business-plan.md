# 📐 事業計画ドラフト — Atelier Kyo

> このドキュメントは、Phase 0 の起点として **kyo-strategist** がリサーチを進めながら継続的に更新します。

## 1. 事業の核心

### 一文で説明すると
> 個人運営の小売店向けに、「**月額制の3D・動的ECサイト構築 + Instagram運用支援**」をワンストップ提供する小さな会社。

### なぜ今か
- 2026年時点で WebGPU が主要ブラウザに普及し、ブラウザ上の3D表現がモバイルでも実用的に
- Shopify Markets により、個人店でも多通貨・多言語インバウンド対応が現実的に
- AI動画生成（Veo / ElevenLabs等）が「個人が映像コンテンツを大量生産する」ことを可能に
- 一方で、個人店の多くは「BASE / STORES への委託」「テンプレートサイト」で停滞しており、見た目で差別化できていない

## 2. ターゲット顧客の解像度

### Primary Segment
- **個人運営の古着屋 / ビンテージショップ / セレクトショップ**
- 横浜・東京・神奈川近郊（対面営業可能エリア）
- インスタグラムは運用しているが、ECは委託 or 持っていない
- 月商：数十万〜数百万円規模
- 海外客（来店）が増えてきており、対応に課題感がある

### Secondary Segment
- スノーボード / バイク / 自転車 / レコード / 雑貨等の専門店
- 仕入れに目利きがあり、商品ストーリーが豊かな個人店

### Non-target
- 大型チェーン店、ファストファッション、メーカー直販
- すでに自社開発チームを持つ法人

## 3. 提供価値（Value Stack）

| レイヤー | 内容 | 競合との差別化ポイント |
|---|---|---|
| L1: 基本ECサイト | Shopify ベースのストア構築・決済・在庫 | 委託サービスより低い月額 |
| L2: 動的・3Dデザイン | Three.js / WebGL / モーションを取り入れた独自UI | テンプレートサイトでは作れない |
| L3: インバウンド対応 | 多通貨・多言語・国際配送設計 | 個人店では難しい設計をパッケージ化 |
| L4: SNS運用支援 | AI動画コンテンツ生成、Instagramコンテンツ制作 | サイト制作と一気通貫 |
| L5: コンサル | 商品撮影・コピー・キャンペーン設計 | 単なる制作会社ではない |

### 想定プラン（月額）

  - Shopify ベース構築（テンプレート利用）
  - 軽量な3Dエフェクト
  - 月1回のメンテナンス
- **Standard（L1+L2+L3）**: ¥XX,XXX / 月
  - 完全カスタムデザイン
  - インバウンド対応（多通貨・多言語）
  - 月2回のメンテナンス
- **Premium（L1〜L5）**: ¥XX,XXX / 月
  - 全機能 + Instagram運用支援
  - AI動画コンテンツ月X本
  - 専任サポート

### 比較対象
- BASE / STORES の委託料：売上の3-5% + 手数料（月商100万なら月3-5万円相当）
- Shopify Basic 単体：$29/月（約¥4,500）+ アプリ・テーマ代
- 一般的なフリーランス制作：初期 50-200万円 + 保守

価格の決め方は、「**月商の5-10%程度に収まる金額**」が現実的な目線。

## 5. 商品開発のフェーズ

### Phase 0 — 環境整備（1週間）
- ✅ エージェントチーム構成（このリポジトリ）
- ⏳ 副業規定の確認
- ⏳ 必要アカウント取得
- ⏳ ロードマップ最終化

### Phase 1 — リサーチ（1-2週間）
- ⏳ 横浜・神奈川・東京の候補店舗 5-10件の調査
- ⏳ 競合・参考サイトのデザイン分析
- ⏳ 提案資料の骨子作成

### Phase 2 — テンプレート構築（2-3週間）
- ⏳ Next.js + Shopify + Supabase のベーステンプレート
- ⏳ 3Dコンポーネントライブラリ（Hero Distortion, Product Orbit, Particle Field, Liquid Blob, Kinetic Typography, Magnetic Cursor, Page Transitions の7種を揃える）
- ⏳ クライアントカスタマイズ機構（`clients/[slug]/config.ts`）

### Phase 3 — 第一クライアント向けデモ（1-2週間）
- ⏳ 1店舗を選んでカスタマイズ
- ⏳ Vercel preview 共有
- ⏳ 提案資料の完成

### Phase 4 — 営業・改善（継続）
- ⏳ デモを持って店舗を訪問・提案
- ⏳ フィードバックループ
- ⏳ 第2・第3クライアントへ横展開

## 6. リスクと対応

| リスク | 影響度 | 対応 |
|---|---|---|
| 証券業の副業規定違反 | 致命的 | 雇用主に書面で確認、必要なら無償デモのみで様子見 |
| 個人店が ¥XX,XXX/月 を払えない | 大 | プラン階層化、初期費用ゼロでハードル下げる |
| 3Dエフェクトが原因でCV低下 | 中 | パフォーマンスバジェット厳守、reduced-motion対応 |
| 制作の属人化（Kyoiskyo一人） | 中 | テンプレート化と、エージェントチームに作業を最大限委譲 |
| Shopifyの規約変更 | 中 | 公式チャンネル定期ウォッチ、複数バックエンド選択肢の研究 |
