# 03 — クライアント受入フロー

> 新規クライアント獲得から運用開始までの **6 ステップ標準フロー**。各段階の所要日数と必要素材を明記。
> **対象読者:** Kyoiskyo（営業・ヒアリング）、kyo-strategist（進行管理）、クラウドデザイン担当者。
> **最終更新:** 2026-05-05

---

## 0. 前提

- 一案件は **クライアント受入から実運用開始まで概ね 4-6 週間**を想定
- Kyoiskyo（営業）とエージェント陣（リサーチ・実装・デザイン委託）の協業前提
- 営業活動・契約締結・金銭発生の手前は Kyoiskyo の判断、それ以降のオペレーションはエージェント主導

---

## STEP 1 — リサーチ・初動 *(所要 3〜7 日)*

### 担当
- **kyo-scout**: 候補ショップの WEB / SNS / 取扱ブランドを公開情報のみから調査
- **kyo-strategist**: リサーチ結果を整理し、Kyoiskyo に提案資料の骨子を提示

### 成果物
- `docs/research/[slug].md`（深掘りレポート、≤600語）
- 推奨デザインムード（6ムードからの選択 + 理由）
- 推奨提案月額レンジ（3 段階の幅）

### Kyoiskyo の作業
- 推奨ムード・価格帯の承認 / 修正
- リード（候補先）への接触可否判断（営業解禁後のみ）

---

## STEP 2 — ヒアリング *(所要 1 日 + 後処理 1 日)*

### 担当
- Kyoiskyo（対面 or オンライン訪問）
- kyo-strategist（事前準備 / 議事録テンプレ）

### 必要素材（クライアントから取得）
- [ ] 屋号・運営者名・連絡先
- [ ] 現在の販売チャネル（実店舗 / Instagram / BASE / STORES / Shop-Pro / Shopify / 委託サービス）
- [ ] 月商規模（**ザックリで OK、契約に必須ではない**）
- [ ] 取扱ジャンル・年代・価格帯
- [ ] 既存顧客像（年代・性別・地域）
- [ ] インバウンド顧客の有無・希望言語
- [ ] 写真撮影の習慣 / 現状の課題
- [ ] ブランドストーリー（口頭で OK、後でテキスト化）
- [ ] ロゴ・既存ブランド資産（あれば）
- [ ] 競合・参考にしたいサイト

### 成果物
- ヒアリング議事録（`docs/research/[slug]-interview.md`）
- 課題仮説の抽出（最大 3 つ）

---

## STEP 3 — 提案 → 契約 *(所要 1〜2 週間、客側のスピード次第)*

### 担当
- **kyo-strategist**: 提案資料の作成
- Kyoiskyo: プレゼン・契約交渉

### 成果物
- 提案書（`templates/proposal-template.md` を埋めたもの → PDF 化）
- 契約書（個別調整、初版テンプレは Phase 1 後半で整備）
- 価格表（`templates/pricing-tiers.md` を参照）

### 提案資料の必須要素
1. 現状の課題サマリ（ヒアリング 3 つから）
2. ATELIER KYO がどう解決するか
3. 想定 KPI（売上 / コンバージョン / インバウンド比）
4. 価格・契約期間
5. デモサイトの URL（営業初期から `atelier-kyo.vercel.app` を使い回す）

### 契約成立のサイン
- 着手金の支払（または 30 日試用合意）
- 必要素材の引き渡し合意
- 公開予定日のすり合わせ

---

## STEP 4 — デザインブリーフ → クラウドデザイン委託 *(所要 1 週間)*

### 担当
- **kyo-stylist**（kyo-strategist が起こしたブリーフをレビュー）
- クラウドデザイン（外部）

### 成果物
- `templates/design-brief-template.md` を埋めたデザインブリーフ
- 写真撮影リスト（必要なら撮影日程の調整も含む）
- BrandTokens の初版（`clients/[slug]/config.ts` ドラフト）

### クラウドデザインへの委託内容
- ロゴリファイン or 新規作成（必要時のみ）
- 写真ディレクション・撮影（必要時、別費用）
- メインビジュアル / Hero ビジュアルの作成
- カラーパレットの最終確定（6 ムードを起点に微調整）

### Kyoiskyo の作業
- クラウドデザインからの納品物確認
- デザイン進行中のクライアント承認取り

---

## STEP 5 — 構築・デプロイ *(所要 1〜2 週間)*

### 担当
- **kyo-architect**（実装）
- **kyo-stylist**（最終ビジュアル統合）
- **kyo-mechanic**（QA・パフォーマンス・a11y）

### 成果物
- `clients/[slug]/` 配下のカスタマイズ群
- Shopify development store（`atelier-kyo-template` から複製）
- Vercel preview deploy URL（client/[slug] ブランチ）
- Lighthouse / axe / Playwright のレポート

### マイルストーン
- M1: スケルトン動作（preview URL 有効、Hello World レベル）
- M2: ビジュアル統合完了（Hero〜Footer 通し見られる）
- M3: パフォーマンス・a11y クリア（Lighthouse 90+ / axe 重大ゼロ）
- M4: 本番ドメイン接続（`yourshop.com` 等）

---

## STEP 6 — 引き渡し → 運用開始 *(所要 1 週間)*

### 担当
- **kyo-mechanic**（最終車検）
- Kyoiskyo（クライアント立会い・操作レクチャー）
- **ops-agent 相当**（Phase 2 で本格化、現状は kyo-strategist 兼任）

### 成果物
- Shopify 管理画面の操作マニュアル（`docs/04-shopify-setup-guide.md` のクライアント版）
- 運用手順書（商品追加 / 写真差し替え / 価格変更）
- お問い合わせ Slack / メール対応窓口
- **Instagram AI 動画パイプライン**（オプション、`docs/05-instagram-ai-pipeline.md`）

### 引き渡し条件
- [ ] Lighthouse mobile 90+
- [ ] WCAG 2.2 AA クリア
- [ ] チェックアウト到達確認
- [ ] 多言語切替確認（最低 ja / en）
- [ ] Shopify Webhook 動作確認（商品更新時に preview URL が更新される）
- [ ] preview URL が Kyoiskyo の手元にあり、提案資料骨子も完成
- [ ] クライアントの初回ログイン確認

---

## 非常時 / よくあるブロッカー

| 状況 | 対処 |
|---|---|
| クライアント側の画像素材が間に合わない | テンプレ内のグラデーション + ナンバーバッジで暫定運用 → 入手次第差し替え |
| 既存 BASE / STORES からの商品移行 | CSV エクスポート → Shopify インポートツール（kyo-architect が手順書化） |
| クライアントが英語サイトに抵抗感 | Phase 1 では ja のみで運用、Phase 2 から en 投入 |
| Vercel の月額利用料が想定外 | Hobby プラン（無料）で 100GB 帯域まではカバー可。超過時に Pro へ |
| Shopify プランの選定 | Basic ($39/月) で開始、月商 50万 を超えたら Shopify ($105/月) を提案 |
