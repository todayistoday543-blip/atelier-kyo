# 05 — Instagram AI 動画パイプライン

> 個人運営の店主にとって最大のボトルネックは「コンテンツ制作の時間」。Atelier Kyo は **AI 動画生成パイプライン**をオプションサービスとして提供し、月額契約に組み込めるようにする。
> **対象読者:** Kyoiskyo（営業時の差別化材料）、運用担当（Phase 2 で本格稼働）、Claude Design（クリエイティブ判断時の参考）。
> **最終更新:** 2026-05-05

---

## 0. なぜこのサービスが必要か

横浜・神奈川エリアのリサーチで、12 候補店舗中 **9 店舗が日本語のみ・写真も自前撮影で時間が取られている**状況が確認されている（`docs/research/list-2026-05-05.md`）。

- 商品撮影に毎週半日
- Instagram Stories / Reels の編集に毎日 1 時間
- 多言語キャプション作成は手付かず

これを **AI 動画 1 本 = 5 分以内 / 月 12 本相当**で解決し、月額に込みで提供する。「店主の時間を取り戻す」訴求。

## 2. 採用ツール

### 2-A. **Claude API (Sonnet 4.6)** — スクリプト・キャプション生成
- 入力: 商品メモ + ブランドトーン定義
- 出力: 30 秒尺のスクリプト（hook / 商品紹介 / CTA の 3 ブロック）+ Instagram キャプション + ハッシュタグ案
- 多言語対応: ja / en / zh-Hant / ko を同時生成
- コスト: 1 動画あたり概算 ¥5–15

### 2-B. **ElevenLabs Pro** — ナレーション生成
- ブランドごとに「専属ナレーター」ボイスをクローニング（店主の許可必須）
- 多言語: 日本語ナレーターが英語を喋る声も再現可能（Eleven Multilingual v2）
- 出力: WAV / 30秒尺
- コスト: 1 動画あたり ¥30–80

### 2-C. **Veo 3 (Google Flow)** — 動画素材生成
- 「夕方の横浜・伊勢佐木町、ヴィンテージのデニムが並ぶ机の俯瞰、35mmフィルムグレイン」のようなプロンプトで 8 秒動画を生成
- 解像度: 1080p 縦長（Reels 用）
- コスト: 1 動画あたり ¥150–400（生成枚数次第）

### 2-D. **C-Dance**（オプション）— ダンス / モーション系
- 商品着用画像 → 自然な動きの 8 秒動画
- 「服が動いて見える」表現でストリート系に強い
- 着用モデルは禁則: クライアントの承認・所有素材のみ使用

### 2-E. **編集テンプレート** — DaVinci Resolve / After Effects
- ムード別に 6 セットの編集テンプレートを作成（Phase 2）
- 字幕デザインを `BrandTokens` の typography に揃える
- アスペクト比: 9:16（Reels / Stories） / 1:1（Feed）

### 2-F. **投稿スケジューラー** — Buffer か Meta Business Suite
- API 経由で予約投稿 / 投稿時間最適化
- クライアントごとに週 3 投稿の運用を標準

## 4. 著作権・ガイドラインの注意

- ❌ **着用モデル**は店主または店主が所有する素材のみ。AI 生成顔は基本不可（ブランド毀損リスク）
- ❌ **既存ブランド**（Levi's, Champion 等）のロゴを目立たせた AI 生成は禁止 → 当該ブランドの商標利用にあたる
- ❌ **競合店の商品/写真**を素材に使わない
- ✅ **店内・店主自身のショット**は積極活用（人格を見せる）
- ✅ **商品単体のテーブルフォト**は AI 生成 OK（Veo 3 が得意）

---

## 5. 出力品質の社内基準

1. **音声**: ノイズなし、明確な発音、ブランドトーンに合致
2. **映像**: 1080p 以上、フレーム落ちなし、色被りなし
3. **字幕**: 日本語は誤字ゼロ（Claude 出力 → 人間レビュー必須）
4. **タイミング**: hook 3 秒以内、CTA 必ず最後 5 秒に挿入
5. **アクセシビリティ**: 字幕は読める速度、コントラスト比 4.5:1 以上

レビューは Kyoiskyo が承認 → 店主が承認 → 投稿、の 2 段階。

## 6. Phase 別ロードマップ

### Phase 2-A（テンプレ着手後 1 ヶ月）
- ムード別の編集テンプレ 6 種を整備（DaVinci）
- Claude スクリプト生成プロンプトの 6 ムード分の調整

### Phase 2-B（着手後 2 ヶ月）
- ElevenLabs ボイスクローニング自動化
- 投稿スケジューラ統合（Buffer API）
- パフォーマンス可視化（Supabase + chart.js）

### Phase 3
- Veo 3 のプロンプトテンプレライブラリ化
- C-Dance の組み込み（クライアントごとに ON/OFF）
- 競合のSNS動画品質を kyo-scout が定期モニタリング → 提案書に反映

## 8. リスク / 注意点

- **Veo 3** の API 利用枠は 2026年5月時点で月間制限あり → 12 動画/月までは無理なく回せる範囲
- **ElevenLabs** の声のクローニングには店主の音声サンプル（5 分以上）が必要 → 営業初訪問時に録音承諾を取る
- **AI 生成と明記**しないと、消費者庁ガイドラインの観点でリスク。投稿ごとに `#AIGenerated` 等のハッシュタグを推奨
- **クライアントのブランド毀損**を避けるため、最初の 1 ヶ月は Kyoiskyo / 店主の二段階承認を必須化
